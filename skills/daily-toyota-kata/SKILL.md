# Daily Toyota Kata

Use an Obsidian-compatible Wiki structure to plan and track work with Toyota Kata:

- `challenges/<challenge>/<target>/` holds each challenge, its targets, and obstacle pages, where experiments, meetings, and messages are logged. Target folders may also contain supporting notes and diagrams.
- `journal/` holds daily notes plus the Wednesday (M&A) and Friday weekly updates.
- `templates/` is the source of truth for note structure. Create them by copying from the skill's `templates/` folder if needed.

Review the following skill reference before working in the following areas:

- **Challenges, targets, obstacles, activity logs:** `challenges.md`
- **Daily notes and weekly updates:** `planning.md`
- **Fixing structure, pre-October 2026 notes, migration:** `maintenance.md`
